# 青禾校园 Demo 实施计划

目标：交付可本地运行、可生产构建的 Vue 3 + Three.js 校园数字孪生演示，延续已确认文章中的六栋建筑与模拟数据。

设计：浅色校园管理台，白色操作面板、淡绿三维底场、深青色操作强调、橙色告警。中文使用本机苹方/微软雅黑，数字用系统无衬线的等宽数字特性；不依赖在线字体。场景是主体，操作面板不堆砌装饰性图表。移动端按场景、数据、时间控制纵向排列。

文件边界：simulation.js 负责确定性帧数据与告警；createCampus.js 负责可导出三维模型；CampusScene.vue 负责加载、相机、拾取和释放；App.vue 负责选择、播放及下载；单元测试检验告警/恢复/汇总，浏览器测试检验真实场景与用户流程。

1. 编写并运行数据行为测试，确认未实现时失败，再完成纯函数。
2. 制作含建筑细节、道路、运动场、植被与入口的校园模型，导出自包含 GLB；保留建筑编号及图层。
3. 构建 Vue 管理台、Three.js 视图、时间播放、楼宇详情、告警中心、图层控制、视角切换与文件下载。
4. 生产构建和浏览器实测，验证选楼、告警、恢复、暂停/重播、移动端、加载失败和下载。
5. 交付源码、构建产物、GLB、模拟数据、Blender 导入导出脚本及中文启动说明。

边界：不修改 sources；数据明确为模拟；不声称 Seed 生成或验证了本项目；GLB 由本项目几何脚本生成，不冒称 Blender 生成。Blender 工具脚本如环境无 Blender 则明确尚未执行。
